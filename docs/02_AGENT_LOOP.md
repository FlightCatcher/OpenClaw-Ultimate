# Agent Loop

一次聊天请求经历以下过程：

```text
读取会话历史
  ↓
召回相关长期记忆
  ↓
按 Token 预算选择上下文
  ├─ 旧消息超限 → 更新滚动摘要
  └─ 保留完整工具调用轮次
  ↓
调用模型
  ├─ 无工具调用 → 返回答案
  └─ 有工具调用
       ↓
     Runtime 执行工具
       ↓
     工具结果写回消息
       ↓
     再次调用模型
  ↓
保存本轮新增消息
```

复杂任务可以先经过 Planner：

```text
用户目标
  ↓
模型生成结构化步骤
  ↓
DAG 校验
  ├─ 拒绝循环依赖
  ├─ 拒绝未知依赖
  └─ 计算拓扑顺序与就绪步骤
  ↓
保存计划与步骤状态
  ↓
Executor 选择就绪步骤
  ↓
Agent Runtime 调用模型与工具
  ↓
持久化 completed / failed、结果和错误
```

## 运行边界

- 每个 Agent 有最大步骤数，避免无限工具循环。
- 工具异常以结构化结果返回模型。
- 上下文裁剪不会拆散工具调用与工具结果。
- 滚动摘要只覆盖已经被裁剪的旧消息。
- 长期记忆仅在语义相关度达到阈值时注入。
- 工作区工具拒绝路径逃逸与私密目录访问。
