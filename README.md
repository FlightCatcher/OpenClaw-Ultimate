# OpenClaw-Ultimate

基于 OpenClaw、Ollama 和 ComfyUI 构建的本地优先 AI Agent 工程。

## 当前硬件

- CPU：AMD Ryzen 5 3600
- GPU：NVIDIA RTX 3060 Ti 8GB
- 内存：16GB
- 系统：Windows 11
- 模型目录：`E:\AI-Models`

## 项目目标

构建一个模块化、本地优先、可扩展的 AI Agent 平台，逐步支持：

- 本地大语言模型
- 模型自动路由
- 任务规划与执行
- 长短期记忆
- RAG 知识检索
- MCP 工具调用
- ComfyUI 图像生成
- 文件、终端和浏览器工具
- 测试、验证与安全控制

## 项目状态

当前阶段：`v0.1 工程初始化`
